## Agentica

[Agentica](https://agentica.symbolica.ai) is a type-safe AI framework that lets LLM agents integrate with your code—functions, classes, live objects, even entire SDKs.

---

## Getting Started

**Need an API key?**  

Visit the [Symbolica Platform](https://www.symbolica.ai/agentica)

**Want to develop locally?**  

Run the [Agentica Server](https://github.com/symbolica-ai/agentica-server)

**SDKs**

- [Python SDK](https://github.com/symbolica-ai/agentica-python-sdk)  
- [TypeScript SDK](https://github.com/symbolica-ai/agentica-typescript-sdk)
